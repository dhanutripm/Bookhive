#BookHive Online Bookstore

A modern, responsive online bookstore showcasing Indian authors and bestsellers, built using semantic HTML5 and CSS3.

Live Demo

Visit BookHive Live Demo

Features

8 Connected Pages: Home, Books, Single Book, Cart, Login, Signup, About, and Contact pages with smooth navigation.

Responsive Design: Mobile-first responsive layouts utilizing modern CSS Grid and Flexbox for seamless viewing across mobile, tablet, and desktop screens.

Visual Styling: Custom brand color palette inspired by traditional books, styled with CSS variables and elegant typography (Playfair Display and Inter).

Interactive UI Enhancements: Smooth hover effects, CSS keyframe animations, and sticky navigation bars.

Forms & Tables: Cleanly structured login, signup, and contact forms with built-in HTML5 validation attributes, plus a structured shopping cart table.

Indian Context: Local pricing in INR (₹) featuring popular Indian authors and cities.

Built With

HTML5: Semantic markup (<header>, <nav>, <main>, <section>, <article>, <footer>) with SEO and Open Graph meta tags.

CSS3:

CSS Variables for centralized theme management.

Flexbox for alignment and layouts (navbars, footers, card rows).

CSS Grid (auto-fit, minmax) for responsive book catalogs.

Media queries for multi-device responsiveness.

Keyframe animations and transitions.

Assets: Organized image structure optimized for web performance.
